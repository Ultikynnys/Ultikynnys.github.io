The SVG sources are distributed intact, renamed for the website's cursor roles:
arrow.svg = default.svg; pointer.svg = pointer.svg; text.svg = text.svg;
move.svg = fleur.svg; resize-h.svg = size_hor.svg; resize-v.svg = size_ver.svg;
resize-se.svg = size_fdiag.svg (NW/SE); resize-sw.svg = size_bdiag.svg (NE/SW).

Each .png is the matching .svg rasterized at the 48×48 display size for the native CSS
cursor fallback (used where the custom overlay cannot run, such as scrollbar drags).
Rendering from vector keeps it crisp; no 32px raster is upscaled.
Upstream shadows are preserved. Hidden raster reference layers are not displayed.
