# AGENTS.md - JobFindingTips (redirect only)

**The instruction set is not in this repository.** It is deliberately kept inside
the private notes so that web scrapers indexing this public site cannot read it.

## What to do

1. Open `JobFindingTips/MyNotes/JobInfo/AGENTS.md` and follow it. That is the
   authoritative instruction set for job-search work here.
2. Read the notes next to it (`Työhaku.md` first) before acting.
3. If `MyNotes` is missing, is not a symlink, or the instruction file is not
   reachable, stop and ask the user. Do not reconstruct the instructions from
   memory or from anything left in this repo.

## Why this file is empty of instructions

`ultikynnys.github.io` is a public repository, so anything written here is
publishable and scrapable. `MyNotes/` is a symlink to a separate, private
repository, which is why the working instructions live there.

Nothing else belongs in this file: no personal data, no application history, no
rules duplicated from the private notes. Keep it a pointer.
